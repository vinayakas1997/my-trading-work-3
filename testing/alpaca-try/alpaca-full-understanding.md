## 1. Bugs Encountered & Fixes

### Bug 1: `NewsClient.get_news()` strips `next_page_token`

- **Symptom**: Each weekly chunk returned exactly 50 articles (the page limit). `result.next_page_token` was `None` even though the raw API had more pages.
- **Impact**: We got only 182 articles instead of the actual 288 for January 2023 — a **37% data loss**.
- **Root cause**: The `alpaca-py` SDK (v0.43.5) `NewsSet` model reads `next_page_token` from the raw response, but the SDK's internal parsing drops it somewhere in the `BaseDataSet` chain.
- **Fix**: Switched to raw `requests` calls to the REST API directly.

**Before (broken):**
```python
from alpaca.data.historical.news import NewsClient, NewsRequest

client = NewsClient(api_key, secret_key)
req = NewsRequest(symbols="AAPL", start=..., end=..., limit=50)
result = client.get_news(req)
articles = result.data["news"]
page_token = result.next_page_token  # ALWAYS None!
```

**After (working):**
```python
import requests

url = "https://data.alpaca.markets/v1beta1/news"
resp = requests.get(url, headers=headers, params=params)
data = resp.json()
articles = data["news"]
page_token = data.get("next_page_token")  # Works correctly
```

### Bug 2: `StockHistoricalDataClient.get_stock_bars()` strips `next_page_token`

- **Symptom**: Returned exactly 10,000 bars (the page limit) for January 2023. The last bar was on Jan 20 — we lost **Jan 21-31**.
- **Impact**: Got 10,000 bars instead of the actual 15,794 — a **37% data loss**.
- **Root cause**: The SDK `BarSet` model has only a `data` field, no `next_page_token`. The raw API response includes pagination tokens.
- **Fix**: Same as above — use raw `requests` calls.

**Before (broken):**
```python
from alpaca.data.historical import StockHistoricalDataClient
from alpaca.data.requests import StockBarsRequest

client = StockHistoricalDataClient(api_key, secret_key)
req = StockBarsRequest(symbol_or_symbols="AAPL", ...)
result = client.get_stock_bars(req)
df = result.df  # Only first 10K rows!
```

**After (working):**
```python
url = "https://data.alpaca.markets/v2/stocks/bars"
resp = requests.get(url, headers=headers, params=params)
data = resp.json()
bars = data["bars"]["AAPL"]
page_token = data.get("next_page_token")
```

---

### Bug 3: Wrong `ALPACA_DATA_BASE_URL` in `.env`

- **Symptom**: `.env` has `ALPACA_DATA_BASE_URL=https://paper-api.alpaca.markets/v2`
- **Problem**: This URL is the **Trading API** (paper trading), not the **Data API**. The Data API lives at `https://data.alpaca.markets`.
- **Impact**: If someone passes this URL as `url_override` to an SDK client, all data calls would fail with 404.
- **Fix**: The current `alpaca-try` scripts don't use this env value (they rely on SDK defaults), so it's harmless for now. But should be corrected to avoid confusion:

```
ALPACA_DATA_BASE_URL=https://data.alpaca.markets
```

---

### Bug 4: Unicode encoding issues on Windows

- **Symptom**: Box-drawing characters (`\u2500\u2500`) caused `UnicodeEncodeError` in PowerShell cp1252 console.
- **Fix**: Replaced all Unicode box-drawing chars with simple ASCII (`--`, `-`, `|`).

## 2. News API Components

### Endpoint

```
GET https://data.alpaca.markets/v1beta1/news
```

### Query Parameters

| Param | Type | Required | Description |
|-------|------|----------|-------------|
| `symbols` | string | No | Comma-separated tickers (e.g. `AAPL` or `AAPL,MSFT`) |
| `start` | datetime | No | RFC-3339 or YYYY-MM-DD. Default: beginning of current day |
| `end` | datetime | No | RFC-3339 or YYYY-MM-DD. Default: current time |
| `limit` | int | No | 1 to 50 per page. Default: 10 |
| `include_content` | bool | No | Include full article body (default: false) |
| `exclude_contentless` | bool | No | Exclude articles without content (default: false) |
| `sort` | string | No | `asc` or `desc` by updated date (default: desc) |
| `page_token` | string | No | Pagination token from previous response |

### Response Fields (per article)

```json
{
  "id": 30306678,
  "headline": "Apple stock rises on strong earnings",
  "source": "Benzinga",
  "url": "https://www.benzinga.com/...",
  "summary": "Apple Inc. reported better-than-expected Q4 earnings...",
  "content": "<p>Apple Inc. (NASDAQ:AAPL) reported...</p>",
  "author": "John Smith",
  "created_at": "2023-01-05T14:30:00Z",
  "updated_at": "2023-01-05T14:30:00Z",
  "symbols": ["AAPL"],
  "images": [
    {"size": "thumb", "url": "https://...thumb.jpg"},
    {"size": "small", "url": "https://...small.jpg"},
    {"size": "large", "url": "https://...large.jpg"}
  ]
}
```

| Field | Type | Avg Size | Notes |
|-------|------|----------|-------|
| `id` | int | 49 B | Unique, stored as string |
| `headline` | string | 140 B | Article title |
| `source` | string | 49 B | Usually "Benzinga" |
| `url` | string | 172 B | Full URL |
| `summary` | string | 146 B | 1-3 sentence snippet |
| `content` | string | **3.7 KB** | Full HTML body, **77% of total size** |
| `author` | string | 55 B | Journalist name |
| `created_at` | string | 61 B | RFC-3339 UTC |
| `updated_at` | string | 61 B | RFC-3339 UTC |
| `symbols` | array | 80 B | Ticker list |
| `images` | array | 333 B | Thumb/small/large URLs (not image data) |

**Total per article (with content): ~4.8 KB**
**Total per article (without content): ~1.1 KB**

### Pagination

- Max 50 articles per page
- Uses `next_page_token` in response
- Loop until `next_page_token` is null/absent

## 6. Recommendations

### 6.1 Store news WITHOUT content (headline + summary only)

**Rationale:**
- Content is **77% of storage** but most of it is HTML markup
- 29% of articles have **empty content** even with `include_content=True`
- The `summary` field (1-3 sentences) is sufficient for:
  - Rule-based sentiment analysis
  - Keyword/ticker extraction
  - Impact scoring
  - FTS5 full-text search
- If full-body analysis is needed later, fetch **on-demand** via `GET /v1beta1/news?id={id}` (1 API call per article)

**If you MUST store content:**
- Store it in a **separate table** (`news_content` or `news_analysis`) linked by article `id`
- Keep the main `articles` table lean for fast queries

### 6.2 Store bars with all fields

- 1-min bars are only **161 B/row** — negligible cost
- Store all fields: `o`, `h`, `l`, `c`, `v`, `n`, `vw`
- Consider downsampling to 5-min or 15-min for long-term storage if disk is a concern
- Use `adjustment=all` for split/dividend-adjusted prices

### 6.3 Pagination pattern (always use raw requests)

```python
import requests

HEADERS = {
    "APCA-API-KEY-ID": API_KEY,
    "APCA-API-SECRET-KEY": SECRET_KEY,
}

def fetch_all_news(symbol, start, end):
    articles = []
    page_token = None
    while True:
        params = {
            "symbols": symbol,
            "start": start,
            "end": end,
            "limit": 50,
            "include_content": "true",
            "exclude_contentless": "false",
        }
        if page_token:
            params["page_token"] = page_token
        resp = requests.get(
            "https://data.alpaca.markets/v1beta1/news",
            headers=HEADERS, params=params, timeout=30
        )
        resp.raise_for_status()
        data = resp.json()
        articles.extend(data.get("news", []))
        page_token = data.get("next_page_token")
        if not page_token:
            break
    return articles
```

Same pattern for bars (different URL and params).

## 7. Sample Script Code Patterns

### News fetch (with pagination)

```python
import requests

headers = {
    "APCA-API-KEY-ID": "your_key",
    "APCA-API-SECRET-KEY": "your_secret",
}

def fetch_news(symbol, start_iso, end_iso, include_content=True):
    articles = []
    page_token = None
    while True:
        params = {
            "symbols": symbol,
            "start": start_iso,
            "end": end_iso,
            "limit": 50,
            "include_content": str(include_content).lower(),
            "exclude_contentless": "false",
        }
        if page_token:
            params["page_token"] = page_token
        resp = requests.get(
            "https://data.alpaca.markets/v1beta1/news",
            headers=headers, params=params, timeout=30
        )
        resp.raise_for_status()
        data = resp.json()
        articles.extend(data.get("news", []))
        page_token = data.get("next_page_token")
        if not page_token:
            break
    return articles
```

### 1-min bars fetch (with pagination)

```python
def fetch_bars(symbol, start_iso, end_iso):
    bars = []
    page_token = None
    while True:
        params = {
            "symbols": symbol,
            "timeframe": "1Min",
            "start": start_iso,
            "end": end_iso,
            "limit": 10000,
        }
        if page_token:
            params["page_token"] = page_token
        resp = requests.get(
            "https://data.alpaca.markets/v2/stocks/bars",
            headers=headers, params=params, timeout=30
        )
        resp.raise_for_status()
        data = resp.json()
        bars.extend(data.get("bars", {}).get(symbol, []))
        page_token = data.get("next_page_token")
        if not page_token:
            break
    return bars
```
