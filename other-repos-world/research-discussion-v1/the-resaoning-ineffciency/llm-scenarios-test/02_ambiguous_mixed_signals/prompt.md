# 02 — Ambiguous / mixed signals

AAPL daily candles lean bullish (higher highs this week), but the
latest news flow is negative (regulatory probe headline) and one
forecasting angle just flipped bearish. You are asked whether to buy now.

Rules:
- Do NOT place a directional order on a partial picture — check at
  least one more evidence source (`get_news` or an angle/feature tool)
  after the price data before deciding.
- If the evidence conflicts, hold: state the uncertainty and place
  NO order. A confident buy on conflicting evidence is the failure mode.
- Use only numbers returned by tools — never guess a price.
- If a key evidence source is unavailable, say so and do NOT order.
