# Version 1

## Overview

Version 1 addressed 6 critical bugs in the initial vinu-strategy release.

## Release Date

2026-07-06

## Issues Fixed

### 1.1: `select_threshold` field parameter fix

**Problem**: `select_threshold` used aggregated signal value instead of specific feature field.

**Solution**: Added `signal_context` parameter to pass feature signals to selection.

**Files Changed**:
- `vinu_strategy/engine/selection.py`
- `vinu_strategy/engine/pipeline.py`

**Code**:
```python
# Before
def select_threshold(universe, signals, field, min_val):
    return [sym for sym in universe if signals.get(field, 0) >= min_val]

# After
def select_threshold(universe, signals, field, min_val, signal_context=None):
    if signal_context and field in signal_context:
        return [sym for sym in universe 
                if signal_context[sym].get(field, 0) >= min_val]
    return [sym for sym in universe if signals.get(field, 0) >= min_val]
```

**Tests Added**:
- `test_select_threshold_with_field`
- `test_select_threshold_with_field_fallback_no_context`

### 1.2: Signal expression evaluator

**Problem**: Signal expression in allocation was dead code, never evaluated.

**Solution**: Implemented safe AST-based expression evaluator.

**Files Changed**:
- `vinu_strategy/engine/expression.py` (new file)
- `vinu_strategy/engine/allocation.py`
- `vinu_strategy/engine/pipeline.py`

**Code**:
```python
def evaluate_expression(expr: str, context: dict[str, float]) -> float:
    tree = ast.parse(expr.strip(), mode="eval")
    _validate(tree)
    return _eval_node(tree.body, context)
```

**Supported Operations**:
- Arithmetic: `+`, `-`, `*`, `/`, `**`, `%`
- Functions: `max`, `min`, `abs`, `round`
- Variable lookup

**Tests Added**:
- 13 tests in `test_expression.py`

### 1.5: Operator parsing robustness

**Problem**: Fixed tuple of operators limited extensibility.

**Solution**: Extracted valid operators into module-level frozenset.

**Files Changed**:
- `vinu_strategy/models/rules.py`

**Code**:
```python
# Before
OPERATORS = ("eq", "neq", "gt", "gte", "lt", "lte", "in", "between")

# After
OPERATORS = frozenset(["eq", "neq", "gt", "gte", "lt", "lte", "in", "between"])

# Detection
valid_ops = [k for k in d if k in OPERATORS]
```

### 1.6: Concurrency + thread safety

**Problem**: Sequential loops for feature/correlation fetching were slow.

**Solution**: ThreadPoolExecutor for parallel fetching, thread-safe clients.

**Files Changed**:
- `vinu_strategy/service.py`
- `vinu_strategy/clients/base.py`

**Code**:
```python
# Before
for sym in universe:
    data = self._features_client.get_features(sym, indicators)

# After
with ThreadPoolExecutor(max_workers=10) as pool:
    fut_to_sym = {
        pool.submit(self._features_client.get_features, sym, indicators): sym
        for sym in universe
    }
    for fut in as_completed(fut_to_sym):
        sym = fut_to_sym[fut]
        data = fut.result()
```

**Thread Safety**:
```python
class BaseClient:
    def __init__(self, base_url):
        self._client = httpx.Client()
        self._lock = threading.Lock()
    
    def get(self, url):
        with self._lock:
            return self._client.get(url)
```
