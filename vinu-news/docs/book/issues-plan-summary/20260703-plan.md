| # | Task | Priority | Effort |

| 1 | Configurable enrichment stages | P0 | Medium |
| 2 | Rate-limited auto-analysis worker | P0 | Medium |

---

### 1. Configurable Enrichment Stages

**Problem:** All 9 enrichment stages run on every article with no opt-out.

**Solution:**
- Add `enrichment` section to `analysis.yaml` with per-stage booleans
- Add `EnrichmentSettings` dataclass to `settings_loader.py`
- Check each stage flag in `enrich_article()` before running
- Disabled stages use sensible defaults (e.g., `sentiment="NEUTRAL"`, `sentiment_score=0`)

**Files:** `analysis/config/analysis.yaml`, `analysis/config/settings_loader.py`, `analysis/enrichment/enrich.py`

---

### 2. Rate-Limited Auto-Analysis Worker

**Problem:** ThreadPoolExecutor per cycle can overwhelm LLM.

**Solution:**
- Replace per-cycle ThreadPoolExecutor with a fixed pool of daemon worker threads
- Use `queue.Queue` with maxsize limit for backpressure
- Workers pull links from queue in a loop
- Submit links from `_maybe_auto_analyze()` with graceful rejection when queue is full
- Proper shutdown on `close()`

**Files:** `vinu_news/service.py`

---

### 3. Fix Duplicate Ticker Extraction

**Problem:** Hardcoded `DEFAULT_MAJOR_TICKERS` fallback when watchlist absent.

**Solution:**
- Remove `DEFAULT_MAJOR_TICKERS` entirely
- Use `watchlist + already-extracted tickers` for alias lookup
- If no watchlist and no tickers extracted, skip alias lookup entirely
- Update `ticker_db.py` to not import removed constant

**Files:** `analysis/enrichment/ticker_extractor.py`, `analysis/enrichment/ticker_db.py`

---

### 4. Single Source of Truth for Settings

**Problem:** `.env` and DB both store `llm_analysis_mode` / `llm_analysis_concurrency`.

**Solution:**
- `.env` sets first-run defaults via `settings_env_defaults()`
- After first run, DB is authoritative
- `NewsService.__init__` reads from DB first, falls back to `VinuConfig`
- Clear documentation in `.env.example`
- Handle runtime mode switch (auto ↔ manual) in `patch_settings()`

**Files:** `vinu_news/service.py`, `.env.example`

---

### 5. Make MAX_WORKERS Configurable

**Problem:** `MAX_WORKERS = 8` hardcoded.

**Solution:**
- Add `VINU_NEWS_MAX_WORKERS` env var with default `8`
- Add `max_workers` field to `VinuConfig`
- Replace constant with `get_max_workers()` function in `rss/config/settings.py`
- Update `parallel_fetcher.py` to use function

**Files:** `config.py`, `rss/config/settings.py`, `rss/fetch/parallel_fetcher.py`

---

### 6. Consolidate Ingestion Methods

**Problem:** `run_ingestion_cycle()` and `run_ticker_news_ingest()` are 90% duplicate.

**Solution:**
- Single `run_ingestion_cycle()` with `source: str = "rss"` parameter
- `source="rss"` → poll RSS feeds; `source="ticker_news"` → fetch Yahoo headlines
- Shared enrichment/filter/persist block after fetch phase
- Keep `run_ticker_news_ingest()` as thin wrapper for backward compatibility

**Files:** `vinu_news/service.py`

---

### 7. Remove skip_post_process Flag

**Problem:** Skipping post-process stores duplicates with no documented use case.

**Solution:**
- Remove `skip_post_process` from `process_batch()` in `pipeline.py`
- Remove from `service.py` — always run full pipeline (NER, cosine dedup, lead pick)
- Remove from `ingestion_pipeline.py`
- Update test to verify dedup behavior instead of skip behavior

**Files:** `analysis/pipeline.py`, `service.py`, `rss/orchestration/ingestion_pipeline.py`, `tests/analysis/test_post_process.py`

---

### 8. Add Hash Collision Fallback

**Problem:** SHA256 of URL only — no collision handling.

**Solution:**
- Add `headline` and `ts` parameters to `article_id_from_link()`
- Hash `link:headline:ts` instead of plain URL
- Collision probability becomes effectively zero

**Files:** `analysis/enrichment/enrich.py`
