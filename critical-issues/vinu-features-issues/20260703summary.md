## Fixed This Session (9 issues)

### Issue #13 — `_ref` allocates `np.full_like` on every call
- **File:** `evaluator.py`
- **Fix:** Added `_nan_like()` helper using `np.empty_like` + targeted NaN fills instead of `np.full_like`. Applied to all 10 rolling functions (`_ref`, `_rolling_apply`, `_rank`, `_quantile`, `_slope`, `_rsquare`, `_resi`, `_idxmax`, `_idxmin`, `_corr`).

### Issue #15 — Union return types force `isinstance` checks
- **File:** `feature_spec.py`
- **Fix:** Added `RecipeRef` dataclass to distinguish recipe references from legacy string names. `parse_feature_input` returns `FeatureSpec | RecipeRef | str` instead of `FeatureSpec | str`.

### Issue #19 — `MockCandleClient` duplicated in 4 test files
- **Files:** `conftest.py`, `test_api.py`, `test_engine.py`, `test_worker.py`, `test_feature_spec.py`
- **Fix:** Consolidated into `tests/conftest.py`. All test files import the shared class.

### Issue #20 — `try/except/else` instead of `pytest.raises`
- **File:** `test_presets.py`
- **Fix:** Replaced with `with pytest.raises(ValueError, match="nope")`.

### Issue #22 — `_apply_env_overrides` mutates `os.environ`
- **Files:** `config.py`, `service.py`, `cli.py`
- **Fix:** `load_config()` now accepts optional `data_dir` and `meta_db_path` kwargs. `FeatureService.__init__` passes these through. CLI uses `_service_from_args()` instead of mutating env vars.

### Issue #26 — Late import in `routes_features.py`
- **File:** `routes_features.py`
- **Fix:** Moved `get_indicator` import to module level (no circular dependency).

### Issue #28 — `indicator_meta_to_dict` returns plain `dict`
- **File:** `feature_catalog.py`
- **Fix:** Added `IndicatorMetaDict` TypedDict for the return type.

### Issue #29 — Schema migration via silent ALTER TABLE loop
- **File:** `sqlite_backend.py`
- **Fix:** Added `_migrate()` method using `PRAGMA user_version` for explicit version tracking.

### Issue #30 — SQL built via string concatenation
- **File:** `sqlite_backend.py`
- **Fix:** Added `_ALLOWED_FILTERS` whitelist for dynamic WHERE clause columns.

### Issue #33 — Blocking I/O in FastAPI
- **File:** `routes_requests.py`
- **Fix:** Converted all route handlers from `def` to `async def`. Added `_run_sync()` helper using `asyncio.to_thread` to offload blocking service calls to a thread pool.
