### Key Improvements

**Configurable Enrichment (`analysis.yaml`):**
```yaml
enrichment:
  priority: true
  sentiment: true
  impact: true
  category: true
  tickers: true
  language: true      # disable if not needed
  threat: true        # disable if not needed
  source_flag: true
  summary_clean: true
  ticker_dominance: true
```

**Rate-Limited LLM Analysis:**
- Fixed worker pool (configurable via `llm_analysis_concurrency`)
- Thread-safe queue with maxsize=1000 for backpressure
- Graceful shutdown on service close
- Runtime mode switch (auto ↔ manual) via `PATCH /settings`

**Cleaner Ticker Extraction:**
- Removed stale hardcoded `DEFAULT_MAJOR_TICKERS`
- Alias resolution uses watchlist + already-extracted tickers
- No magic defaults — explicit configuration only

**Unified Settings:**
- `.env` provides first-run defaults only
- DB is authoritative after first run
- `patch_settings()` handles runtime mode switching

**Configurable Parallelism:**
- `VINU_NEWS_MAX_WORKERS` env var (default: 8)
- Set to 1 for low-memory environments

**Consolidated Ingestion:**
```python
# Before: Two separate methods with 90% duplicate code
service.run_ingestion_cycle(...)
service.run_ticker_news_ingest(...)

# After: Single method with source parameter
service.run_ingestion_cycle(source="rss", ...)
service.run_ingestion_cycle(source="ticker_news", tickers=["AAPL"], days=7)
```

**Always Run Post-Process:**
- NER, cosine dedup, and lead selection always execute
- Consistent data quality — no duplicate storage
- `skip_post_process` flag fully removed
