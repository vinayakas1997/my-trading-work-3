# Issue: vinu-features Dashboard Health Section Shows Broken Fields

**Date:** 2026-07-06

## Bug Found

The Dashboard health section references two fields that do **not exist** in the backend response:

1. `health.info?.db_size_bytes` — always renders as `-`
2. `health.info?.request_count` — always renders as `-`

## Root Cause

The backend `health_info()` at `sqlite_backend.py:304-318` only returns:
- `db_path`
- `status_counts`

The actual `/health` response shape is:
```json
{ "info": { "db_path": "...", "status_counts": {...}, "data_dir": "...", "stock_api_url": "..." } }
```

The Dashboard at `Dashboard.jsx` was written assuming fields (`db_size_bytes`, `request_count`) that the backend never provided.

## Files Affected

| File | Issue |
|---|---|
| `web/src/components/Dashboard.jsx` | Reads non-existent fields from health response |
| `vinu_features/storage/sqlite_backend.py` | Doesn't expose `db_size_bytes` or `total_request_count` |
| `vinu_features/service.py` | Doesn't expose catalog/preset counts in health |
