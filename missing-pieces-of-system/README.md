# missing-pieces-of-system

Each subfolder here is a design doc for a piece of the system that isn't
built yet (or is partially built).

**Naming convention:** if a folder's name is prefixed with `(comp)`, that
piece is fully implemented — the design has been built and verified, not
just written. Folders without the `(comp)` prefix are still design-only /
not yet (fully) implemented.
