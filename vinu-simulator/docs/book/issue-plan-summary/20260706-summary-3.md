## Fixes Applied

### P0 — NaN/Inf / division by zero / data corruption

| Issue | Description | Change |
|-------|-------------|--------|
| ZC1-1 | `SimulatorEnv.step()` missing NaN price validation | Added `if np.any(~np.isfinite(prices)): raise ValueError(...)` after price extraction on each step |
| ZC1-2 | Missing NaN deviation guard | Added `if not np.isfinite(deviation): pass` before `elif deviation > threshold` — skip rebalance silently |
| ZC1-3 | Zero-price guard in sell loop | Added `if prices[idx] <= 0: continue` before `shares_to_sell = -delta * nav_before / prices[idx]` |
| ZC1-4 | Missing finite check on shares_to_sell | Added `if not np.isfinite(shares_to_sell): continue` before `<= 1e-12` check |
| ZC1-5 | Zero-price guard in buy loop | Added `if prices[idx] <= 0: continue` before `target_shares = target_values[idx] / prices[idx]` |
| ZC1-6 | Missing finite check on shares_to_buy | Added `if not np.isfinite(shares_to_buy): continue` before `<= 1e-12` check |
| ZC1-7 | `np.errstate(divide="ignore")` still present | Removed the suppress wrapper; `np.where(pv > 0, ...)` already guards the zero-value branch |
| ZH1 | Division by zero in metrics when initial value is 0 | Guarded `portfolio_values / portfolio_values.iloc[0]` and `total_return` with `if initial_value > 0` |
| ZH2 | `FlatCostModel.sell_proceeds` returns negative for extreme slippage | Clamped: `return max(0.0, effective_price * shares * (1 - cost_pct))` |

### P1 — Side effects / resource leaks

| ZM2 | `SimulatorAPI` missing context manager | Added `__enter__` / `__exit__` delegating to `self._service.close()` |
