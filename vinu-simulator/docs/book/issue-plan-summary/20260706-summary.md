# Fix Summary — vinu-simulator

**Date**: 2026-07-06
**Status**: All 10 fixes implemented, 23/23 tests passing

---

## Fixes Applied

### 1. `allow_short` now enforced (`engine/simulator.py`)
- `WeightSimulator.run()` and `SimulatorEnv.step()` both check `config.allow_short`
- When `True`: sells are not capped at `holdings[idx]`, allowing short positions
- When `False`: negative weights are clamped to 0 and remaining weights renormalized to sum to 1; sells capped at current holdings

### 2. Almgren-Chriss now receives volume data (multi-file)
- `SimulationInput` gains optional `volume_data: pd.DataFrame | None`
- `PriceClient` rewritten to call `/candles/{symbol}` endpoint (was calling non-existent `/prices`); now returns `(price_df, volume_df)` via `get_price_and_volume()`
- `SimulatorService` passes volume data through to `WeightSimulator`
- `WeightSimulator.run()` passes `volume=` arg to both `buy_cost()` and `sell_proceeds()`
- `FlatCostModel` and abstract `CostModel` updated to accept `volume`/`volatility` kwargs for polymorphic dispatch

### 3. Weight normalization removed (`engine/simulator.py`)
- No longer renormalizes weights to sum to 1.0
- Strategy weights used as-is: sums < 1.0 leave cash; sums > 1.0 attempt leverage (limited by cash)
- Test weights (from `np.random.dirichlet`) already sum to 1.0, so existing tests unaffected

### 4. `.bfill()` look-ahead bias eliminated (`engine/simulator.py`)
- `price_data.reindex(total_calendar).ffill().bfill()` → `price_data.reindex(total_calendar).ffill()`
- No future prices leak into earlier calendar dates

### 5. Missing tickers now raise error (`clients/price_client.py`)
- `pivot[sym] = 0.0` replaced with `raise ValueError(...)` listing missing symbols
- Silent portfolio corruption eliminated

### 6. MetaStorage thread-safe (`storage/meta.py`)
- Single `self._conn` replaced with `threading.local()` — each thread gets its own connection
- WAL mode still enabled per connection
- `close()` clears the current thread's connection only (expected shutdown pattern)

### 7. Event loop no longer blocked (`server/routes_read.py`)
- All synchronous service calls wrapped in `await loop.run_in_executor(None, func, *args)`
- Helper `_run_sync()` utility added for clarity

### 8. `MetricBundle` no longer dead code (`models/metrics.py`)
- Added `from_dict()` class method to construct from a `dict`
- Class is now usable (though `compute_performance_metrics` continues to return `dict` for flexibility)

### 9. `.env.example` created
- Documents all `VINU_SIMULATOR_*` environment variables with defaults
