## Fixes Applied

### P0 — Data corruption / silent failure

| Issue | Description | Change |
|-------|-------------|--------|
| C1 | `delete_run()` / `delete_runs()` missing `conn.commit()` | Added `conn.commit()` after each DELETE in both methods |
| C2 | NaN/Inf silently propagates through simulation | 5 sub-fixes: (1) validate prices are finite each date, (2) guard `prices[idx] <= 0` before division, (3) remove `np.errstate(divide="ignore")` wrapper, (4) validate `shares_to_sell` / `shares_to_buy` are finite, (5) validate `deviation` is finite |
| C3 | `.ffill()` on reindex leaves NaN for early dates | After `.ffill()`, check `price_data.isna().any(axis=None)` → raise `ValueError` with date/ticker details |

### P1 — Wrong results under specific conditions

| Issue | Description | Change |
|-------|-------------|--------|
| H2 | `or` operator prevents setting zero values via API | Replaced `req.X or default` → `req.X if req.X is not None else default` for `initial_capital`, `transaction_cost_pct`, `slippage_pct`, `deviation_threshold` |
| H8 | `target_values` stale after sells reduce NAV | Recompute `nav_after_sells = cash + np.sum(holdings * prices)` then `target_values = nav_after_sells * rebalance_weights` before the buy loop (fixed in both `WeightSimulator.run()` and `SimulatorEnv.step()`) |
| H9 | `BaseClient.close()` not thread-safe | Acquire `self._lock` inside `close()` before calling `self._client.close()` |
| H10 | `MetaStorage.__init__` crashes if parent dir missing | Added `db_path.parent.mkdir(parents=True, exist_ok=True)` in `__init__` |
| H11 | `MetaStorage.close()` leaks connections from other threads | Added `self._connections: set[Connection]` + `self._close_lock`; register each new connection in `_get_conn()`; close all in `close()` |

### P2 — Usability / edge cases

| Issue | Description | Change |
|-------|-------------|--------|
| M9 | AC `sell_proceeds` can return negative proceeds | Clamped: `return max(0.0, effective_price * shares - fixed - impact)` |
| M10 | No validation on `start_date`/`end_date` format | Added `pattern=r"^\d{4}-\d{2}-\d{2}$"` via `Field` in Pydantic schema |
| M11 | Benchmark ticker env var with spaces parses incorrectly | Strip whitespace: `t.strip() for t in bm_raw.split(",")` |
| M12 | `slippage_model` accepts any string | Changed to `Literal["flat", "almgren_chriss"]` in Pydantic schema; added `ValueError` in `_build_cost_model` for unknown models |

### P3 — Cleanup / ergonomics

| Issue | Description | Change |
|-------|-------------|--------|
| L10 | O(n) containment check per simulation date | Pre-computed `rebalance_dates = set(weight_signals.index)` before loop |
| M13 | `SimulatorService` has no context manager | Added `__enter__` / `__exit__` calling `self.close()` |
