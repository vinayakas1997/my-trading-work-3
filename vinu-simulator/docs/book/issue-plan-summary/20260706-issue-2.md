# Second Code Audit — vinu-simulator

**Date**: 2026-07-06  
**Scope**: Second-pass deep review — logic gaps, data integrity, edge cases missed in first audit

## Critical Issues

### C1. `delete_run()` / `delete_runs()` missing `conn.commit()` — deletions silently roll back
**File**: `vinu_simulator/storage/meta.py`, lines 104-119  
**Problem**: `insert_run()` has `conn.commit()`, but both `delete_run()` and `delete_runs()` execute DELETE SQL and return `cur.rowcount > 0` **without ever calling `conn.commit()`**. Python's sqlite3 runs DML inside implicit transactions that are rolled back on connection close unless explicitly committed. Users see `true` returned but data never actually removed.  
**Introduced by**: Thread-safety refactor in the first fix pass.

### C2. NaN/Inf silently propagates through entire simulation
**File**: `vinu_simulator/engine/simulator.py`, lines 67, 87, 94, 120, 123, 147, 170-182  
**Problem — multiple avenues for corruption**:

| Location | Problem |
|----------|---------|
| Line 67 | `reindex(total_calendar).ffill()` leaves NaN for dates before first price data |
| Line 94 | `nav_before = cash + np.sum(holdings * prices)` → NaN if prices contain NaN |
| Line 101 | `NaN > 0` is `False` → `current_weights` stays all zeros, masking upstream NaN |
| Line 111 | `deviation = np.abs(...).sum()` → NaN; `NaN > threshold` is `False` → rebalance skipped silently |
| Line 120 | `shares_to_sell = -delta * nav_before / prices[idx]` → Inf if `prices[idx]` is 0 |
| Line 123 | `Inf <= 1e-12` is `False` → Inf shares trade without guard |
| Line 147 | `target_shares = target_values[idx] / prices[idx]` → Inf if price is 0 |
| Lines 170-172 | `NaN <= 0` is `False` → NaN not clamped to 0 |
| Lines 180-182 | `np.errstate(divide="ignore", invalid="ignore")` **intentionally silences** all division/NaN warnings |

### C3. Price `.ffill()` on reindex leaves NaN for early dates
**File**: `vinu_simulator/engine/simulator.py`, line 67  
**Problem**: `price_data.reindex(total_calendar).ffill()` — when `total_calendar` (union of price + weight dates) starts before any price exists, `.ffill()` has nothing to propagate and prices remain NaN. C2 cascade follows.  
**Introduced by**: Fix in first pass that removed `.bfill()` to eliminate look-ahead bias, but added no guard for leading NaN.

## High Issues

### H2. `or` operator prevents setting zero values via API
**File**: `vinu_simulator/service.py`, lines 59-66  
**Problem**: `req.initial_capital or self._config.initial_capital` evaluates `0.0 or default` → `default` because `0.0` is falsy. Same bug for `transaction_cost_pct`, `slippage_pct`, `deviation_threshold`. Users **cannot** set any of these to zero.

### H8. `target_values` computed before sells — stale after NAV changes
**File**: `vinu_simulator/engine/simulator.py`, lines 113, 147  
**Problem**: `target_values = nav_before * rebalance_weights` is computed **once** at line 113 before the sell loop (lines 115-141). Sells reduce NAV via transaction costs. The buy loop at lines 143-168 uses the stale `target_values`, causing buys to target an allocation that no longer matches available capital. Same bug in `SimulatorEnv.step()` at lines 277/295.

### H9. `BaseClient.close()` not thread-safe — race with `get()`/`post()`
**File**: `vinu_simulator/clients/base.py`, lines 19-31  
**Problem**: `get()` and `post()` acquire `self._lock`, but `close()` calls `self._client.close()` **without the lock**. If `close()` runs concurrently with a request, `httpx.Client` may close mid-flight, causing a cryptic transport error.

### H10. `MetaStorage.__init__` crashes if parent directory missing
**File**: `vinu_simulator/storage/meta.py`, lines 11-16  
**Problem**: `sqlite3.connect(str(db_path))` raises `OperationalError` if the parent directory does not exist. `ResultStorage.__init__` calls `mkdir(parents=True, exist_ok=True)` but `MetaStorage` does not.

### H11. `MetaStorage.close()` leaks connections from other threads
**File**: `vinu_simulator/storage/meta.py`, lines 121-124  
**Problem**: `close()` only closes the calling thread's connection. Connections created by other threads (e.g., from `run_in_executor` thread pool) remain open indefinitely.

## Medium Issues

### M9. Almgren-Chriss `sell_proceeds` can return negative proceeds
**File**: `vinu_simulator/engine/costs.py`, line 108  
**Problem**: For large orders with high market impact, `effective_price * shares - fixed - impact` can go negative. Seller *pays* to exit a position, which adds cash instead of removing it.

### M10. No validation on `start_date`/`end_date` format
**File**: `vinu_simulator/server/schemas.py`, lines 11-12  
**Problem**: Plain `str` fields. Invalid date strings crash deep inside `pd.Timestamp()` with no useful error message to the API caller.

### M11. Benchmark ticker env var with spaces parses incorrectly
**File**: `vinu_simulator/config.py`, lines 53-54  
**Problem**: `VINU_SIMULATOR_BENCHMARK_TICKERS=SPY, QQQ` (with space) parses as `("SPY", " QQQ")`. The space-prefixed `" QQQ"` never matches `price_data.columns` and is silently skipped.

### M12. No validation on `slippage_model` — unknown values silently fall back to `flat`
**File**: `vinu_simulator/server/schemas.py`, line 16; `engine/simulator.py`, lines 32-41  
**Problem**: `slippage_model: str = "flat"` accepts any string. `slippage_model="no_such_model"` silently falls back to `FlatCostModel` with no warning.

### M13. `SimulatorService` has no context manager (`__enter__`/`__exit__`)
**File**: `vinu_simulator/service.py`  
**Problem**: Users must remember to call `.close()`. No `with` statement support, so connections may leak on exception.

**Problem**: `date in weight_signals.index` is O(n) on `pd.DatetimeIndex`. Should use a pre-computed `set()`.
