## Issues to Fix

### 2.1: Risk stage breaks on negative weights (short signals)

**Severity**: Critical

**Problem**: `risk_normalize` uses `min(w, max_w)` which passes negative weights through unchanged, causing division by zero or negative scale.

**Example**:
```python
# Input: {"AAPL": 0.167, "MSFT": -0.167}
# Current: capped_total = 0.0, scale = 0.9 / 0.0 -> ZeroDivisionError
# Expected: Separate long/short handling
```

**Solution**:
1. Split weights into longs and shorts
2. Separate capping: `max_weight` for longs, `max_short_weight` for shorts
3. Scale both proportionally if gross exposure exceeds limit

**Files to Modify**:
- `vinu_strategy/engine/risk.py`
- `tests/test_risk.py`

**Implementation**:
```python
def _risk_normalize_with_shorts(weights, max_w, max_short_w, cash_floor):
    longs = {sym: min(w, max_w) for sym, w in weights.items() if w >= 0}
    shorts = {sym: max(w, -max_short_w) for sym, w in weights.items() if w > 0}
    
    gross = sum(longs.values()) + abs(sum(shorts.values()))
    limit = 1.0 - cash_floor
    
    if gross > limit:
        scale = limit / gross
        longs = {sym: w * scale for sym, w in longs.items()}
        shorts = {sym: w * scale for sym, w in shorts.items()}
    
    result = {}
    result.update(longs)
    result.update(shorts)
    return result
```

**Tests to Add**:
- `test_normalize_with_shorts` - Mixed long/short weights
- `test_normalize_shorts_exceed_cap` - Scale when shorts exceed limit
- `test_normalize_allow_short_false` - Long-only mode

### 2.2: Expression evaluator is case-sensitive for feature names

**Severity**: High

**Problem**: vinu-features API supports case-insensitive names (`SMA_9` = `sma_9`), but expression evaluator does strict dict lookup.

**Solution**:
1. Normalize keys to lowercase in `_extract_feature_values()`
2. Add fallback lookup in `evaluate_expression()`: try key as-is, lowercase, uppercase

**Files to Modify**:
- `vinu_strategy/service.py`
- `vinu_strategy/engine/expression.py`

**Implementation**:
```python
def _extract_feature_values(self, data, indicators):
    values = data.get("values", data)
    values_dict = {k.lower(): v for k, v in values.items()}
    for ind in indicators:
        raw = values_dict.get(ind.lower())
        result[ind] = float(raw) if raw is not None else 0.0
```

### 2.4: Parquet append is O(n) per write

**Severity**: Medium

**Problem**: Each append reads entire year's file, concatenates, rewrites. Slow for large datasets.

**Solution** (choose one):
- **Option A**: Per-day Parquet files (`{year}-{month}-{day}.parquet`)

**Files to Modify**:
- `vinu_strategy/storage/weights.py`

**Severity**: Low

**Problem**: Strategies have `schedule: daily | weekly` but no scheduler executes them.

**Solution**:
1. Add `apscheduler` dependency
2. Implement `vinu-strategy schedule` command
