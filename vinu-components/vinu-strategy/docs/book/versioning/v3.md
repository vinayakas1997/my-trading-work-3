## Planned Enhancements

### 3.1: `--verbose` / `--log-level` CLI flag

**Severity**: Low

**Problem**: Logging level hardcoded to `WARNING`. No way to see INFO/DEBUG without code modification.

**Solution**: Add `--log-level` CLI flag.

**Files to Modify**:
- `vinu_strategy/cli.py`

**Implementation**:
```python
def main(argv=None):
    parser = argparse.ArgumentParser()
    parser.add_argument("--log-level", default="WARNING",
                       choices=["DEBUG", "INFO", "WARNING", "ERROR"])
    
    args = parser.parse_args(argv)
    logging.basicConfig(level=getattr(logging, args.log_level))
```

**Usage**:
```bash
vinu-strategy evaluate ma_crossover AAPL --log-level DEBUG
```

### 3.3: No retry logic in API clients

**Severity**: Medium

**Problem**: Transient failures return empty dict, no retry.

**Solution**: Add retry with exponential backoff.

**Files to Modify**:
- `vinu_strategy/clients/base.py`

**Implementation**:
```python
from tenacity import retry, stop_after_attempt, wait_exponential

@retry(stop=stop_after_attempt(3), wait=wait_exponential(multiplier=1, min=1, max=10))
def get(self, url):
    try:
        return self._client.get(url)
    except httpx.RequestError as e:
        LOG.warning(f"Request failed: {e}, retrying...")
        raise
```

**Behavior**:
- 3 retry attempts
- Exponential backoff: 1s, 2s, 4s
- Log warnings on retries

### 3.4: No strategy CRUD via API

**Severity**: Low

**Problem**: Strategies managed only via YAML files, no runtime API.

**Solution**: Add POST/PUT/DELETE endpoints.

**Files to Modify**:
- `vinu_strategy/server/routes_config.py`

**Endpoints**:
- `POST /strategies` - Create strategy from YAML
- `PUT /strategies/{name}` - Update strategy
- `DELETE /strategies/{name}` - Delete strategy

**Implementation**:
```python
@router.post("/strategies")
async def create_strategy(yaml_content: str):
    config = parse_yaml(yaml_content)
    registry.add(config)
    meta.register_strategy(config.name, config.description, config.schedule)
    return {"name": config.name, "status": "created"}

@router.delete("/strategies/{name}")
async def delete_strategy(name: str):
    registry.remove(name)
    return {"name": name, "status": "deleted"}
```

### 3.5: Stale data persists when strategies are deleted

**Severity**: Low

**Problem**: Deleting strategy YAML doesn't clean up weights/runs.

**Solution**: Cascade delete on strategy removal.

**Files to Modify**:
- `vinu_strategy/server/routes_config.py`
- `vinu_strategy/storage/weights.py`
- `vinu_strategy/storage/meta.py`

**Implementation**:
```python
@router.delete("/strategies/{name}")
async def delete_strategy(name: str):
    registry.remove(name)
    
    # Cascade delete
    weights_deleted = storage.delete_weights(name)
    runs_deleted = meta.delete_runs(name)
    
    return {
        "name": name,
        "weights_deleted": weights_deleted,
        "runs_deleted": runs_deleted
    }
```

### 3.6: Web UI could show richer evaluation results

**Severity**: Low

**Problem**: UI shows only final weights, no intermediate pipeline outputs.

**Solution**: Add `--trace` to API, display in UI.

**Files to Modify**:
- `vinu_strategy/api.py`
- `web/src/components/StrategyDashboard.jsx`

**Implementation**:
```python
def evaluate(self, strategy_name, symbols):
    result = self._service.evaluate(strategy_name, symbols)
    resp = {
        "strategy_name": result.strategy_name,
        "run_id": result.run_id,
        "weights": result.weights.to_dict(orient="records"),
        "rule_trace": result.rule_trace,  # Include trace
        "pipeline_stages": {  # New: intermediate outputs
            "selection": pipeline_meta.get("selection"),
            "allocation": pipeline_meta.get("allocation"),
            "timing": pipeline_meta.get("timing"),
            "risk": pipeline_meta.get("risk")
        }
    }
    return resp
```

**UI Enhancement**:
- Show rule trace per symbol
- Display intermediate weights per stage
- Visualize rule firing
