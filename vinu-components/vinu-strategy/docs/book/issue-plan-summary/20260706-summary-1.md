# vinu-strategy: Version 1 Summary

Date: 2026-07-06

---

## Overview

Version 1 addressed 6 issues in the vinu-strategy codebase. All fixes are implemented, tested (56/56 tests passing), and verified with runtime integration tests.

---

## Changes Made

### 1. `select_threshold` field parameter fix

- **`selection.py`**: Added `signal_context` parameter to `select_threshold`. When `field` is specified (e.g., `on: MOM_20`), the function now looks up that specific feature in the signal context instead of using the aggregated signal value. Falls back to original behavior when context is unavailable.
- **`pipeline.py`**: Passes `signal_context` from the pipeline to `run_selection`.
- **Tests**: Added `test_select_threshold_with_field` and `test_select_threshold_with_field_fallback_no_context`.

### 2. Signal expression evaluator

- **New file `expression.py`**: Safe AST-based expression evaluator. Parses expressions using `ast.parse()`, validates the AST tree against an allowed node whitelist, and evaluates with a context dict. Supports arithmetic (`+`, `-`, `*`, `/`, `**`, `%`), built-in functions (`max`, `min`, `abs`, `round`), and variable lookup. Rejects dangerous nodes (attribute access, arbitrary function calls, etc.).
- **`allocation.py`**: Updated `allocate_signal_scaled` to accept `signal_context`. When a `signal` expression is in params and context is available, evaluates the expression per-symbol. Preserves the sign of the expression result for directional signals. Falls back to original `abs()`-based behavior when no expression is specified.
- **`pipeline.py`**: Passes `signal_context` to `run_allocation`.
- **Tests**: 13 tests in `test_expression.py` covering arithmetic, functions, edge cases, and safety. 4 new tests in `test_allocation.py` covering expression evaluation, RSI mean reversion, and fallback behavior.

### 3. Correlation flattening cleanup

- **`service.py`**: Removed redundant nested `if` block (lines 73-76) that pre-flattened impact/correlation data. `_flatten_correlation_context()` already handles all dict-typed values correctly.

### 4. Risk params hardcoded defaults

- **`pipeline.py`**: Removed hardcoded `0.25` and `0.10` fallbacks. Now only sets defaults from the `params` dict if it's provided. The `risk_normalize` function retains its own documented defaults.

### 5. Operator parsing robustness

- **`rules.py`**: Extracted valid operators into module-level `frozenset`. Changed operator detection to use list comprehension (`[k for k in d if k in OPERATORS]`) instead of iterating a fixed tuple.

### 6. Concurrency + thread safety

- **`service.py`**: Replaced sequential `for sym in universe` loops with `ThreadPoolExecutor(max_workers=10)` for both feature and correlation fetching. Added `_fetch_correlation_for_symbol` helper method.
- **`base.py`**: Added `threading.Lock` to `BaseClient` to make `httpx.Client` calls thread-safe when shared across threads.
