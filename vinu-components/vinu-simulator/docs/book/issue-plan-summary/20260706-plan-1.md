# Code Audit — vinu-simulator

**Date**: 2026-07-06
**Scope**: Full logic, data handling, missing components review

---

## Critical Bugs (Logic Issues)

### 1. `allow_short` flag never checked
`SimulationConfig` has `allow_short: bool = True` but neither `WeightSimulator.run()` nor `SimulatorEnv.step()` ever read this flag. Both always prevent short positions with `shares_to_sell = min(shares_to_sell, holdings[idx])` — holdings can never go negative. The config field exists but the engine never acts on it.

### 2. Almgren-Chriss cost model effectively disabled
`WeightSimulator._build_cost_model()` creates `AlmgrenChrissCostModel` but never passes volume/volatility data. `_participation_rate()` returns 0 when `volume is None`, so market impact is always 0. The AC model degenerates into `FlatCostModel`.

### 3. Weight normalization erases cash allocation intent
`simulator.py:68-71`: all weights normalized to sum to 1.0. If a strategy wants 10% cash (weights: 0.3, 0.3, 0.3 → sum 0.9), normalization converts them to ~0.33 each, investing 100%.

### 4. `.bfill()` introduces look-ahead bias
`simulator.py:64`: `price_data.reindex(total_calendar).ffill().bfill()`. If the calendar starts before price data, `.bfill()` uses future prices to fill earlier dates.

---

## Improper Data Handling

### 5. Missing tickers silently assigned price 0.0
`price_client.py:60-61`: `pivot[sym] = 0.0` if ticker not found. A price of 0.0 makes `holdings * prices = 0`, wiping out assets with no warning.

### 6. MetaStorage not thread-safe
`meta.py:13`: single `sqlite3.connect()` without `threading.local()`, despite `tips.md` explicitly warning against this pattern.

### 7. FastAPI routes block the event loop
`routes_read.py:24`: `async def simulate()` calls `svc.simulate(req)` (synchronous) directly, without `run_in_executor`. Long simulations block all requests.

---

## Missing Components

### 8. Web UI (`server/static/`) missing
Directory referenced in `pyproject.toml` and mounted in `app.py` does not exist. Other services have built React UIs.

### 9. `MetricBundle` dataclass is dead code
Defined in `models/metrics.py` but never instantiated — `compute_performance_metrics()` returns a plain `dict`.

### 10. No `.env.example` file
`.gitignore` has `!.env.example` pattern but file does not exist.

### 11. No service/storage layer tests
Only engine tests exist. Zero tests for `SimulatorService`, HTTP routes, `MetaStorage`, `ResultStorage`.
