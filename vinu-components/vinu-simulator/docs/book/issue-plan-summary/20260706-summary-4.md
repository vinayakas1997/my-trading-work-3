## Fixes Applied

### I4-1 — Context manager leaves closed service accessible (MEDIUM)

**File:** `vinu_simulator/api.py`

**Before:** `__exit__` closed the service but kept `self._service` pointing to the dead instance.
```python
def __exit__(self, *args):
    if self._service is not None:
        self._service.close()
```

**After:** The reference is cleared so `_get_service()` creates a fresh one on next access.
```python
def __exit__(self, *args):
    if self._service is not None:
        self._service.close()
        self._service = None
```
