## Crypto Analysis Framework

### On-Chain Metrics

| Metric | Definition | Signal |
|--------|------------|--------|
| MVRV Ratio | Market Cap / Realized Cap | > 3.5 = top, < 1 = bottom |
| NVT Ratio | Network Value / Transaction Volume | High = overvalued |
| SOPR | Spent Output Profit Ratio | < 1 = capitulation |
| Exchange Netflow | Inflow - Outflow | Outflows = accumulation |
| Active Addresses | Unique addresses/day | Growth = adoption |
| Hash Rate | Mining computing power | Network security proxy |

### DeFi Analysis
- **TVL (Total Value Locked)**: protocol health, > $1B = established
- **Revenue/Fees**: protocol sustainability, P/S ratio
- **Staking Yield**: token inflation rate vs staking APR
- **Impermanent Loss**: AMM LP risk in volatile pairs
- **Liquidations**: cascading liquidation risk levels

### Tokenomics Checklist
- [ ] Total supply: fixed vs inflationary vs burned
- [ ] Vesting schedule: cliff + linear unlock
- [ ] VC unlock dates (major selling pressure events)
- [ ] Staking ratio (high = good for price support)
- [ ] Governance: voting power distribution
- [ ] Treasury: size, diversification, runway

### Risk Framework
- **Regulatory**: SEC classification (security vs commodity), jurisdiction
- **Technical**: Smart contract risk (audit count, audit age, bug bounty)
- **Market**: Liquidity depth, spread, order book shape
- **Counterparty**: Exchange risk (FTX-style collapse), custody
