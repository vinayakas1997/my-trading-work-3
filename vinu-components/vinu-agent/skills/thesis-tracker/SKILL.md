## Thesis Tracking Framework

### Thesis Structure
```
Hypothesis: {concise statement of edge}
Universe:   {specific securities}
Entry:      {price/valuation condition}
Catalyst:   {specific event or timeframe}
Target:     {price target (+X%) or valuation target}
Stop:       {exit if wrong (-Y%)}
```

### Status Pipeline
| Status | Meaning | Next Action |
|--------|---------|-------------|
| Investigating | Initial research | Gather data, set up alerts |
| Active | Position opened | Monitor catalyst |
| Watching | Pre-catalyst, not yet in | Set price alerts |
| Closed — Hit | Thesis played out, target met | Record P&L, review accuracy |
| Closed — Stopped | Thesis invalidated | Record loss, root cause analysis |
| Closed — Expired | Catalyst passed, no move | Archive for future reference |

### Catalyst Calendar
- Earnings dates, FDA decisions, FOMC dates, CPI releases
- M&A deadlines, lockup expirations, index rebalancing
- Dividend ex-dates, shareholder meetings, rights offerings

### Thesis Scoring (1-5)
| Dimension | 1 | 3 | 5 |
|-----------|---|---|---|
| Conviction | Low edge | Good edge | Asymmetric edge |
| Timing | No catalyst | Soft catalyst | Hard catalyst date |
| Risk/Reward | < 1:1 | 2:1 | > 3:1 |
| Different | Consensus | Contrarian | Unique insight |
