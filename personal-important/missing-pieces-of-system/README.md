# missing-pieces-of-system

Each subfolder here is a design doc for a piece of the system that isn't
built yet (or is partially built).

**Naming convention:**
- `(comp)` prefix — fully implemented. The design has been built and
  verified, not just written.
- `(pcomp)` prefix — partially implemented. Some real, working pieces
  exist and are verified, but the doc still lists features left to
  build (check the doc's own "pending" section for what's actually
  left before treating it as done).
- No prefix — still design-only, not yet (even partially) implemented.
