# vinu-correlation: Design Plan (v2 — Advanced Agentic-Grade)

Date: 2026-07-06

---

## Vision

The bridge between `vinu-news` and `vinu-stock-price` that **mathematically proves news impact on price movements** — with statistical rigor, market-hours awareness, and a native Python API for the Agentic Strategy Researcher.

The Risk Critic Agent calls `vinu_correlation.get_impact("AAPL")` and gets back structured evidence:

```python
{
  "high_impact_bearish_events": 4,
  "avg_price_drop_30m": -1.2,
  "drawdown_attribution": [
    {"headline": "AAPL revenue miss", "attribution_pct": 0.40, "sentiment": "BEARISH"},
    {"headline": "iPhone supply cut", "attribution_pct": 0.25, "sentiment": "BEARISH"},
  ],
  "correlation_stats": {
    "granger_p_value": 0.023,
    "best_lag_minutes": 15,
    "news_return_corr": 0.32,
    "ci_95": [0.12, 0.51]
  }
}
```

## Market Hours Segmentation (`engine/market_hours.py`) — NEW IN v2

Split analysis by trading session to eliminate noise from overnight gaps:

| Session | Hours (ET) | bar_ts range (UTC) | Treatment |
|---------|-----------|--------------------|-----------|
| Pre-market | 4:00–9:30 | 8:00–13:30 | Separate baseline, higher volatility expected |
| Regular | 9:30–16:00 | 13:30–20:00 | Primary analysis window |
| After-hours | 16:00–20:00 | 20:00–00:00 | Separate baseline, lower liquidity |
| Closed | 20:00–4:00 | 00:00–8:00 | Skip or flag as `closed` |

```python
# engine/market_hours.py
from datetime import datetime, timezone, timedelta
from dataclasses import dataclass

@dataclass
class SessionInfo:
    name: str          # pre_market / regular / after_hours / closed
    utc_start_hour: int
    utc_end_hour: int

# NYSE calendar: ET = UTC - 4 (EDT) or UTC - 5 (EST)
# Simplified: assume UTC-4 for ET.
# In production, use exchange_calendars or pandas_market_calendars.

def classify_session(ts: int) -> SessionInfo:
    """Classify a unix timestamp into market session."""
    dt = datetime.fromtimestamp(ts, tz=timezone.utc)
    hour = dt.hour
    if 8 <= hour < 13:    # Pre-market
        return SessionInfo("pre_market", 8, 13)
    elif 13 <= hour < 20: # Regular
        return SessionInfo("regular", 13, 20)
    elif 20 <= hour < 24: # After-hours
        return SessionInfo("after_hours", 20, 24)
    else:                 # Closed
        return SessionInfo("closed", 0, 8)

def impact_window_within_session(article_ts: int, window_sec: int) -> tuple[int, int]:
    """Return the (from_ts, to_ts) for price lookup, respecting session boundaries.

    If the window extends past the session end, truncate to session close.
    This prevents measuring overnight gaps as price impact.
    """
    session = classify_session(article_ts)
    if session.name == "closed":
        return (article_ts, article_ts)  # no valid window
    session_end = session.utc_end_hour * 3600
    article_day_start = (article_ts // 86400) * 86400
    max_ts = article_day_start + session_end
    return (article_ts, min(article_ts + window_sec, max_ts))
```

**Configuration options:**
```python
market_hours_only: bool = True        # Skip closed-session articles
session_break_on_close: bool = True    # Truncate windows at session boundaries
```

## HTTP Client Pattern (`net.py`)

Extend the existing `vinu-news/net.py` pattern with timeout and retry:

```python
def request(method, url, *, timeout=30, retries=3, **kwargs):
    """HTTP request with timeout, retry, and Docker loopback fallback."""
    for attempt in range(retries):
        try:
            return requests.request(method, url, timeout=timeout, **kwargs)
        except requests.ConnectionError as e:
            if "Connection refused" not in str(e) or attempt == retries - 1:
                if attempt == 0:
                    fallback = _docker_fallback_url(url)
                    if fallback:
                        url = fallback
                        continue
                raise
            time.sleep(1 * (2 ** attempt))  # exponential backoff
```

## Engine Modules — Detailed

### 1. `engine/market_hours.py` — Session Segmentation (NEW)

See section above. Provides:
- `classify_session(ts: int) -> SessionInfo`
- `impact_window_within_session(article_ts, window_sec) -> (from_ts, to_ts)`
- `NYSE_SESSIONS` constant
- Should use `exchange_calendars` or `pandas_market_calendars` in production for holiday-aware session detection

### 2. `engine/impact.py` — Per-News-Event Impact (Upgraded)

- Fetch articles from `vinu-news` via `GET /articles/since?since_ts={from}&until_ts={to}`
- For each article:
  - Parse tickers (primary + secondary, see Multi-Ticker section)
  - Classify market session
  - Fetch candles from `vinu-stock-price` via `GET /candles/{symbol}?from={sort_ts}&to={sort_ts+86400+3600}`
  - Compute price change for ALL windows (5m, 15m, 30m, 1h, 1d) using session-aware boundaries
  - Compute abnormal return via `event_study.compute_abnormal_return()`
  - Classify each event:
    - `high_bearish`: sentiment=BEARISH AND |change| >= impact_high_threshold
    - `high_bullish`: sentiment=BULLISH AND |change| >= impact_high_threshold
    - `medium`: |change| >= impact_medium_threshold
    - `low`: |change| < impact_medium_threshold
  - Aggregate thread-level impact if `thread_id` is present
- Write results to Parquet: `{data_root}/correlation/{SYMBOL}/{YYYY}.parquet`
- **Reuse note:** Read precomputed `price_change_1h`/`price_change_1d` from `article_price_reaction` when available to avoid redundant computation

### 3. `engine/event_study.py` — Event Study (NEW)

- Estimate expected return from pre-event window (e.g., 7-day rolling average return)
- Compute abnormal return: `AR = R_actual - R_expected`
- Compute Cumulative Abnormal Return (CAR) over event window
- t-test significance: p-value for null hypothesis `CAR = 0`
- Classify: `significant_positive`, `significant_negative`, `insignificant`
- Returns structured dict for each event

### 4. `engine/granger.py` — Granger Causality (NEW)

- Resample news intensity into 1h buckets
- Resample price returns into 1h buckets
- Test lags 1–12 (hours)
- Return best lag + p-value
- Uses `statsmodels.tsa.stattools.grangercausalitytests`

### 5. `engine/correlation.py` — Time-Series Correlation (Upgraded)

- Resample news into 1h buckets: article count, avg_sentiment, avg_impact_score per bucket
- Resample price into 1h returns: `(close_t+1h - close_t) / close_t`
- Align time series
- Compute Pearson + bootstrap CI + p-value
- Lag analysis: shift news series 15m, 30m, 1h forward; report `best_lag_minutes`
- Granger causality test
- Store aggregated correlation matrices in `{YYYY}_correlation.parquet`

### 6. `engine/drawdown.py` — Drawdown Attribution (Upgraded)

- Scan price series for peak-to-trough drawdowns > `drawdown_min_pct` (default -3%)
- For each drawdown:
  - Collect news events in `drawdown_lookback_hours` (default 24h) lookback window
  - Collect market returns for same window (if available)
  - Fit OLS: `price_return = β₁·news_intensity + β₂·market_return + ε`
  - Compute attribution percentages from normalized coefficients
  - Attribute individual event contributions within news_driven_pct
- Return structured evidence with per-event attribution

### 7. `engine/baseline.py` — Deviation Detection (Upgraded)

- 7-day rolling hourly article count per ticker **per session**
- Session-specific z-scores: `(current - session_mean) / session_stddev`
- Flag deviations: `normal` (z<2), `elevated` (2-3), `high` (3-4), `critical` (>4)
- Store baselines in `{data_root}/correlation/{SYMBOL}/{YYYY}_baseline.parquet`

## Key Design Decisions (v2)

1. **Dual interface:** Native Python API (`api.py`) is primary; FastAPI is a thin HTTP wrapper. The `vinu-research` agent imports directly in-process.
2. **All windows from day one:** 5m, 15m, 30m, 1h, 1d — computed in one pass. No deferral.
3. **Market hours segmentation by default:** Without it, overnight gaps destroy correlation signal. Session-specific baselines.
4. **Event study methodology:** Abnormal returns + CAR + p-values replace raw price_change for statistical rigor.
5. **Granger causality:** Tests temporal direction — the difference between "correlated" and "causes."
6. **Bootstrap confidence intervals:** Every correlation includes uncertainty bounds.
7. **Multi-factor drawdown attribution:** Not binary — attribution percentages for news, market, and unexplained components.
8. **Incremental compute:** Continuous data arrival handled with append + periodic compaction. 1h overlap for edge effect safety.
9. **Story thread aggregation:** Leverages existing `vinu-news` threads for cumulative narrative impact.
10. **TTLCache:** Agent may query same symbol repeatedly in research iterations. Cache avoids redundant computation.
11. **Multi-ticker handling:** Primary ticker gets full weight; secondary tickers get 0.5x confidence weight.
12. **Synthetic test harness:** Generate known ground-truth data to validate statistical engines.
